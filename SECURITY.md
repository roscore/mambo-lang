# Security policy / 보안 정책

Version 0.1.0 is the supported version. Mambo executes untrusted source with bounded steps, stack size, and loop depth, but it is not a security sandbox. Do not run the CLI with privileges or expose it directly as a network service.

Please report suspected vulnerabilities privately using GitHub's repository security advisory feature at `https://github.com/roscore/mambo-lang/security/advisories/new` if available. If it is unavailable, open an issue requesting a private contact channel without including exploit details. Include a minimal reproducer, affected version, expected impact, and your contact information. Maintainers will acknowledge reports as capacity allows; no response deadline is guaranteed.
